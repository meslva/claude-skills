# 제안서 PDF 가져오기

`~/Desktop/이전제안서/`는 이전 제안서를 쌓아 두는 아카이브다.

```
이전제안서/
├── pdf/   원본 PDF
└── md/    같은 이름의 .md (검색하고 LLM이 읽기 위한 텍스트 버전)
```

md 파일은 형식이 정해져 있고, 기존 파일도 모두 이 형식으로 만들어졌다. 형식이 같아야 나중에 grep이나 페이지 번호(`<!-- p.N -->`)로 원본 쪽수를 찾아갈 수 있으므로, 직접 변환하지 말고 스크립트를 쓴다.

## 실행 방법

```bash
python3 <이 스킬 폴더>/scripts/import_pdf.py "<PDF 경로>" ["<PDF 경로>" ...]
```

- `<이 스킬 폴더>`는 이 SKILL.md가 있는 폴더다 (git clone 설치면 `~/.claude/skills/pdf2md`, 플러그인 설치면 플러그인 캐시 안의 `pdf2md`).
- 스크립트가 PDF를 `pdf/`에 복사(파일명 유지)하고 `md/<같은 이름>.md`를 생성한다.
- `--root DIR`: 아카이브 위치가 다를 때만 지정한다(기본값 `~/Desktop/이전제안서`).
- `--force`: 같은 이름이 이미 있을 때 덮어쓴다. **사용자가 덮어써도 된다고 확인한 경우에만** 붙인다. 기존 md를 사람이 손봤을 수 있기 때문이다.
- 필요 도구: poppler의 `pdftotext`, `pdfinfo` (없으면 `brew install poppler` 안내).

pdf/ 에 이미 있는 PDF의 md만 없다면 그 PDF 경로를 그대로 넘기면 된다(자기 자신에게는 복사하지 않고 변환만 한다).

## 결과 해석과 보고

스크립트는 파일마다 한 줄씩 출력한다.

- `[OK] ... (N쪽, 빈 페이지 K)`: 성공. 사용자에게 저장 위치와 쪽수를 짧게 알린다.
- `[EXISTS]`: 같은 이름이 이미 있다. 덮어쓸지 사용자에게 물어본 뒤, 원하면 `--force`로 다시 실행한다.
- `[SKIP]`: PDF가 아니거나 경로가 틀렸다. 경로를 확인한다.
- `⚠ 텍스트 없는 페이지`: 대부분 페이지에서 텍스트가 안 나왔다는 뜻으로, 스캔 이미지 PDF일 가능성이 크다. md는 거의 비어 있으므로 사용자에게 알리고 OCR이 필요한지 묻는다(`ocrmypdf`로 텍스트 레이어를 입힌 뒤 다시 가져오기 등).

변환이 끝나면 md 파일 앞부분(제목·원본 줄·첫 몇 페이지)을 한 번 훑어보고 한글이 깨지지 않았는지 확인한다.

## md 형식 (참고)

```
# <파일명(확장자 제외)>

원본: ../pdf/<파일명>.pdf · <총 쪽수>쪽

<!-- p.1 -->
## p.1

<pdftotext -layout 으로 뽑은 해당 페이지 텍스트, 앞뒤 공백 제거>

<!-- p.2 -->
## p.2
...
```
