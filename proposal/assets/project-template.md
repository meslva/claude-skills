## 4. 브랜드 설정 (PPT)

템플릿이 있으면 `python <스킬>/scripts/deck.py --inspect <템플릿>`으로 도형 이름을 확인해 `PROTO`를 채운다(`references/05-ppt.md`).

```python
TEMPLATE = None   # 템플릿 경로
BRAND = {
    "company": "",
    "doc_title": "",
    "font": "나눔스퀘어",          # 회사 가이드 기본. 템플릿이 다른 글꼴을 쓰면 그것을 따른다
    "font_bold": None,             # 굵은 글꼴이 따로 있으면(예: "페이퍼로지 7 Bold")
    "density": 3,                  # 기본 밀도 1~5(내용의 양: 높을수록 내용을 더해 빈 공간을 채움). /제안서 ppt 밀도=N 이 우선
    # "text_scale": 0.75,          # 도식 안 글자 배율(밀도와 무관)
    # "primary": "", "secondary": "", "accent": "",   # 무채색 + 고객사 키 컬러
}
PROTO = None      # 템플릿 원형 장표 복제 설정(템플릿이 있을 때)
```
