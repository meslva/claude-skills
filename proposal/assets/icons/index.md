# 아이콘 라이브러리

회사 공통 가이드(상세)와 수주 제안서(양부대 스마트물류)에서 추출한 아이콘 345개. 파일명은 `iNNN_출처슬라이드.png`.

- 눈으로 고를 때: `_catalog_01.jpg` ~ `_catalog_05.jpg` (회색 배경, 빨간 번호)
- 코드: `d.icon(slide, (x, y, w, h), "i245")` 또는 `d.icon(..., "보안")`처럼 이 표의 키워드로 찾는다(첫 번째 일치).
- 출처: 가이드 아이콘(i001~i217) 다수는 flaticon(CC 3.0 BY) 등 외부 무료 아이콘이다. 회사 가이드가 이미 쓰던 자산이며, 외부 공개 문서에 쓸 때는 가이드의 출처 표기 관례를 따른다.
