## 2. 판형·글꼴·크기

- 판형: A4 가로 10.83 × 7.5인치(템플릿이 있으면 템플릿 판형).
- 글꼴: **나눔스퀘어**(가이드 권장). 사업 템플릿이 다른 글꼴(예: 페이퍼로지)을 쓰면 템플릿을 따른다. 설치 확인된 글꼴: 나눔스퀘어, Pretendard, 페이퍼로지 1~9, 맑은 고딕.

## 3. 색

- 원칙: **무채색 + 고객사 키 컬러.** 그라데이션·그림자 금지.
- 기본(고객 키 컬러가 없을 때): 남색 `#002060`, 파랑 `#123E8C` / `#175491` / `#2F5597`, 패널 `#F5F7FB`, 본문 `#414141`, 보조 글자 `#808080`.
- 수치·주의 강조: 빨강 `#DC2F34`(숫자, (*) 주석, 비용·범위 경계).
- 순서색(01~04 카드·기둥): 하우스 기본 `163E64 / 3B7D23 / 0B76A0 / 7B2672`. 고객 톤이 파랑 계열이면 같은 계열 4단계로 바꾼다(예: 글로비즈 `0B2A5B / 004A8D / 0072CE / 2E9BD6`). `BRAND["seq"]`.
- 한 장표의 강조색은 한두 곳.

## 4. 번호 체계

`Ⅰ.`(장) → `1.`(절) → `1.1`(장표 제목) → `①`(항목). **1.1.1은 되도록 쓰지 않는다**(아이콘 소제목으로 대신). 카드·단계 번호는 `01, 02, 03`.

## 5. 본문 장표 구성(슬롯)

위에서 아래로 다음 슬롯을 채운다. 비워도 되는 것은 (선택).

| 슬롯 | 내용 | deck.py |
|---|---|---|
| 제목 | `1. 무중단 인프라 전환`(명사구) | `content_slide(title)` |
| 머리글 | 장 / 절 | `section="Ⅱ. 구축 방안 > 1. 시스템 구축 전략"` |
| 헤드메시지(GM) | 합니다체 1~2문장, 핵심어 **굵게**(키 컬러) | `headline="… **핵심어** …"` |
| 슬로건 (선택) | 가운데 따옴표 명사형 대구: “미리 검증하는 리허설, 경매 없는 시간의 전환” | `slogan=` |
| 영문 키워드 (선택) | `Rehearsal · Cut-over · Rollback` | `keywords=` |
| 주 도식 | 본문 영역의 60~80% | 6장 패턴 |
| 보조 블록 | 주 도식 옆·아래: 탭 패널, KPI 띠, 표, 라벨 행 | `tab_panel`, `kpi_strip`, `table`, `label_desc_rows` |
| 하단 요약 바 (권장) | 아이콘 + 색 제목 + 한 줄 설명 3~4칸 = 장표 결론 | `summary_bar` |
| 도장 (해당 시) | 예시·Sample·목표치 | `stamp` |
| 출처 | ※ RFP p8, 요구사항 1-1 #1 | `source=` |

상세 가이드의 GM 구성: **리드 문장(회색) + 헤드라인(파랑 굵은 명사구)** → 도식 → 하단 결론 라벨/각주. 템플릿에 헤드라인 자리가 하나뿐이면 리드는 생략하고 헤드라인에 핵심어 굵게를 쓴다.

**밀도 기준**(자사 수주 제안서 실측): 장표당 도형 50~100개, 아이콘 5~20개. 컴포넌트 하나로 영역을 늘려 채우지 않는다 — 주 도식 + 보조 블록 + 요약 바로 채운다.

## 6. 문체

- 헤드메시지: **합쇼체**(~합니다), 1~2문장, "방법 → 결과" 2절 구조가 기본: "경매가 없는 시간대 일괄 전환과 2회 리허설로 / 실시간 경매 중단 없이 전환을 끝냅니다."
- 본문: 개조식, 명사형 종결. 한 항목 한 줄 반 이내.
- **정량 근거를 모든 장표에.** 숫자가 없으면 [근거 필요].
- 범위·비용 경계는 `(*)` 각주로 명시(빨강).
- 추상어(최적화, 고도화, 효율화)만으로 끝나는 문장 금지 → `style-guide.md`.

## 7. 표·강조·주석

- 표: **좌우 세로선 없음**, 머리글 위 선 1pt(주색), 안쪽 가로선 0.25pt. `deck.table`이 이 규칙으로 그린다.
- 강조: 굵게 + (필요 시) 밑줄 + 키 컬러. 키 컬러가 없으면 파랑.
- 수치 강조·주의: 빨강 `#DC2F34`.
- 주석: `(*)` 표시 후 장표 하단에 7~8pt.

## 8. 장별 구성 규칙

| 장 | 필수 구성 | 권장 도식 |
|---|---|---|
| 사업 이해 | 배경 → 현황·문제 → 요구 정리(고객명 명시) | `compare`, `chart`, `hub_quadrant` |
| 추진 전략 | **목표 → CSF → 전략 → ACTION** 순. 여러 장이면 제목 뒤 `(n/N)(관점)` | `pillar_matrix` + `summary_bar`, `cycle_ring`(결론) |
| 요건 구현 방안 | 좌측 LNB(요구사항 목록) + "구축전략 ▶ 주요내용" 2단 | `label_desc_rows`, `tab_panel`, `screen_callout` |
| 시스템 구성 | 계층 구조 + 신규·변경 강조 | `layers`, `hub_quadrant` |
| 수행 방법·일정 | 단계, 산출물, 일정 | `process`, `step_rail`, `timeline` |
| 품질·보안·운영 | 등급·절차·SLA | `pyramid`, `swimlane`, `table` |
| 조직·인력 | 조직도 + R&R | `org`, `table` |
| 요구사항 대응 | RTM: 요구 ID ↔ 반영 장표 | `table` (자사 수주 제안서는 80개 요구를 쪽 번호로 매핑) |

발표용 요약본은 장표마다 질문 태그(WHY / WHAT / HOW)를 달고, 상세는 부록으로 뺀다.

## 9. 하우스 스타일(자사 수주 제안서 실측 — 양부대)

템플릿이 없을 때 이 틀을 기본으로 한다. 글로비즈 템플릿도 같은 계열이다.

- 틀: 회색 `#D9D9D9` 배경 + 흰 본문 카드(0.24, 1.23, 10.37×6.26).
- 제목: 20pt 페이퍼로지 8 ExtraBold `#0076C0`, 좌상(0.09, 0.05).
- 머리글: 장 8pt / 절 12pt `#215F9A` 우측 정렬.
- 헤드메시지: 14pt(0.26, 0.57), 합니다체 2절.
- 슬로건: 16pt `#0076C0` “ ” 가운데(1.40인치 높이) / 영문 키워드 9pt `#808080`(1.85).
- 본문 영역: y 2.14~7.0, 맨 아래 요약 바.
- 반복 장치: 패널에 걸친 탭 라벨, "01 + 영문 + 국문" 카드 머리, 순서색 4색, 원 아이콘, 예시 도장, 점선 행 구분.
