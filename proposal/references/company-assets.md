# 회사 자산 처리

회사 자료는 정리되어 있지 않다는 전제로 다룬다. 자료가 없다고 작업을 멈추지 않는다.

## 착수 시 요청 목록

| 자산 | 쓰이는 곳 | 없을 때 |
|---|---|---|
| PPT 템플릿(.pptx/.potx) | 5단계 PPT | 기본 디자인으로 만들고 "임시 디자인" 표시 |
| 이전 수주 제안서·좋은 장표 샘플 | 도식 패턴 학습(`visual-patterns.md` 5장) | 기본 패턴 라이브러리 사용 |
| 회사 소개(연혁·조직·인원) | 5장 제안업체 일반 | [자산 필요: 회사 연혁·조직도] |
| 재무 현황(최근 3년) | 5장 | [자산 필요: 재무 3개년] |
| 유사 수행 실적(사업명·발주처·기간·금액·내용) | 차별화 근거, 5장 | [자산 필요: 유사 실적 — ○○ 분야] |
| 방법론·표준 산출물 | 3장 사업관리 | 일반 방법론 구조 + [자산 필요: 회사 방법론 명칭] |
| 인력 프로필(등급·경력·자격) | 3장 투입 인력, 인력 요약표 | [자산 필요: PM·AA·DBA 프로필] |
| 보유 솔루션·도구·특허 | 차별화, AI 활용 | [자산 필요: 보유 도구] |

## 규칙

- **지어내지 않는다.** 실적·인력 경력·수치를 만들어 내면 허위 기재가 된다. 비슷한 예시도 넣지 않는다.
- 받은 자료는 `제안작업/자산/`에 원본을 두고, 요약본을 `제안작업/자산/자산목록.md`에 정리한다(자산명, 파일, 핵심 내용, 쓰인 장표).
- 여러 사업에 재사용할 자료는 사용자가 정한 **공용 자산 폴더**에 복사하고 경로를 `project.md`에 적는다. 다음 사업 착수 때 그 폴더부터 확인한다.
- 원고의 [자산 필요]는 검수 보고에서 목록으로 모아 누가 채울지 정할 수 있게 한다.
