# 문체·말투 규칙

## 대화
- 사용자에게는 존댓말(~습니다/~입니다/~하시겠습니까). 반말·평어체 금지.
- 쉬운 말로 설명하고, 전문용어는 처음 나올 때 괄호로 풀이한다.
- "쉽게 말하면:", "간단히 말해:" 같은 상투적 머리말을 쓰지 않는다.
- 결과 보고는 짧게: 만든 파일 링크 → 핵심 요약 → 확인할 점.

## 문서
| 문서 | 문체 |
|---|---|
| 분석보고서, 용어사전, 전략_목차, 검수보고서 | 하다체 |
| 질의서(발송용) | 격식 존댓말("~확인 요청드립니다") |
| 질의서(내부관리) | 쉬운 하다체, 짧은 문장 |
| 설명회 질의 "말로 읽을 질문" | 말하는 존댓말("~여쭙고 싶습니다") |
| 제안서 원고 헤드메시지 | 완결된 주장 문장(기본 합니다체) |
| 제안서 원고 본문 | 개조식(명사형 또는 ~함, 장 안에서 통일) |

## 모호 표현 (제안서에서 쓰지 않는다)

한국 공공·대기업 RFP는 흔히 "모호한 표현은 불가능으로 간주"한다고 적는다. 아래 표현은 단정형으로 바꾼다.

| 피할 표현 | 바꾸는 방향 |
|---|---|
| ~할 수 있다 / ~할 수 있음 / ~가 가능하다 | ~한다 / ~함 / ~를 제공한다 |
| ~될 수 있다 / 공급될 수 있다 / 사용 가능하다 | ~된다 / 공급한다 / 사용한다 |
| ~를 고려하겠다 / 고려하고자 한다 / 고려하고 싶다 | ~를 적용한다(적용 대상·시점 명시) |
| ~를 검토하겠다 / 검토 예정 | ~를 수행한다, 또는 대안 비교 후 권고안 명시 |
| 노력하겠다 / 최선을 다하겠다 | 무엇을, 몇 번, 언제, 어떤 기준으로 하는지 |
| 최대한 / 가급적 / 가능한 한 | 구체 수치·기준 |
| ~등을 통해 (핵심 방법이 "등"에 묻힘) | 방법을 모두 열거 |
| 예정이다 (시점 없이) | 시점을 붙인다(착수 후 2주 이내 등) |
| 필요 시 ~ | 조건을 명시(○○ 발생 시) |

예외: 발주처의 선택지를 설명하는 문장(예: "발주처 요청 시 추가 제공 가능")은 맥락을 보고 판단하되, 가능하면 "요청 시 ○일 이내 제공"처럼 조건과 약속으로 바꾼다.

## 슬로건
- 헤드메시지 아래 따옴표 문구는 **명사로 끝낸다.** "~한다/~다"로 끝내지 않는다. 헤드메시지(합니다체)는 이 규칙 대상이 아니다.
- 한자어로 압축하지 말고(“선확정·선제 제거·단일화”는 딱딱하다), 원문의 대구와 말맛을 살려 **"~하는 ○○" 꼴**(꾸며 주는 말 + 명사)로 쓴다. 예: "규칙을 먼저 정하고, 입찰은 한곳에서" → "먼저 정한 규칙, 한곳에서 하는 입찰".
- 기존 장표의 슬로건을 바꿀 때는 asis/tobe 표를 먼저 보여 주고 승인받는다.

## 한 페이지는 하나의 이야기
- **강조한 단어에는 같은 페이지 안에 근거가 있어야 한다.** 헤드메시지·소제목·결과 칸에 쓴 핵심어(예: "운영 효율", "마스킹")를 뒷받침하는 내용(대상·기준·수치)이 그 페이지에 없으면 근거를 더하거나 핵심어를 바꾼다. 근거는 RFP·Q&A·본문 상세 장표에서 가져온다.
- **어려운 용어는 작은 회색 첨언으로 뜻을 단다**(한 줄, 하한 8pt).
- **페이지 주제와 무관한 구역은** 관련 내용으로 바꾼다.
- **약점을 드러내는 부정 표현**(실패, 장애 가능성 등)은 대응 약속 문장으로 바꾸고, **예측할 수 없는 효과**(오류 ○% 감소 등 근거 없는 효과 수치)는 쓰지 않는다.

## 근거 표기
- 요구사항 엑셀은 **[시트] 셀 주소 (No.)**까지 적는다. 예: `[2-1] G15 (No.8 As-is)`, `[4-2] I20~I25 (No.3~8 비고)`. "2-1-#8" 같은 약식은 쓰지 않는다. 시트 약칭은 문서 머리에 전체 시트명과 함께 정의한다. 시트 위쪽에 샘플 행이 있으면 No와 행 번호를 혼동하지 않는다.
- RFP는 쪽수(`RFP p8`), 발주처 답변은 질의 번호(`Q&A Q2`)로 적는다.
- **RFP 개정 버전 표기**("v1.01 추가 요건", "(개정 추가)")는 제안서 본문에 넣지 않는다. 평가위원에게 의미 없는 내부 구분이다.

## 용어 통일
- 같은 대상은 제안서 전체에서 같은 이름으로 부른다. 발주처 문서의 표기를 우선한다.
- 영문 약어는 장별 첫 등장 시 풀이한다.
- 숫자 단위: M/M, 개월, 명, 건, 본(프로그램 수) 중 하나로 통일.
